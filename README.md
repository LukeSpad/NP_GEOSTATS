# NP_GEOSTATS
Non-Parametric Space Time Geostatistics via Gaussian Simulation

This program implements Stephen Henley's proposed modification of the kriging algorithm for non IID cases, using a modified Mann Whitney U test to derive the final Kriging weights. I produced this to provide some assistance to El Salvadorian colleauges who were attempting to model spatial variations in homicide rates. The work remains experimental and was never fully completed, but I'm sharing the code in case helpful.

Nonparametric geostatistics provides methods for spatial analysis and modeling that don't rely on restrictive assumptions about the data distribution or spatial structure, offering flexibility in situations where traditional geostatistical techniques might not be suitable. This approach is particularly useful when dealing with non-Gaussian data or when the spatial relationship is complex and not well-described by standard variogram models.
